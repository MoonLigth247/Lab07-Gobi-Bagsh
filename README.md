## Хэсэг E: Дүгнэлт (debrief)

Энэхүү 60 минутын exploratory тестийн session-ийн үеэр "Уншлагын жагсаалт" вэб аппын хэд хэдэн чухал согогийг илрүүлж, баримтжуулсан. Хамгийн үр дүнтэй аялал бол **Supermodel (GUI)** байлаа. Учир нь хэрэглэгчийн интерфэйс дээрх өнгө, формат, мессежүүдийг шалгах явцад BUG-01 (хоосон мөр нэмэгдэх), BUG-02 (Устгах товч ногоон өнгөтэй байгаа), BUG-03 (хайлт том/жижиг үсэг ялгах) зэрэг алдаануудыг илрүүлсэн. Мөн **Saboteur (API түвшин)** аялалаар `curl` команд ашиглан шалгах үед BUG-04 буюу дутуу талбартай JSON хүсэлтийг сервер 400 алдаа буцаахын оронд 201 Created гэж хүлээн авч, хоосон утгатай ном хадгалж байгааг нотолсон.

Charter-аас гадуур санамсаргүйгээр оны формат буруу харагдаж байгааг (`1971` биш `1,971`), мөн оны талбарт тоо биш оролт (`abc`) оруулахад `NaN` гэж харагдахыг анзаарсан. Эдгээр нь анхны төлөвлөгөөнд тусгайлан оруулаагүй ч тестийн явцад илэрсэн. Дараагийн session-ийн charter-т XSS халдлага болон хүснэгтийн давхардлын шалгалтыг оруулах шаардлагатай гэж үзэж байна.

Эдгээр согогуудын дотроос BUG-04 (API согог) болон BUG-03 (хайлт) нь Лаб 1-ийн Playwright автомат тестээр амархан баригдах байсан. Учир нь API-ийн хариу статусыг шалгах, эсвэл хайлтын үр дүнг баталгаажуулах скрипт бичихэд хангалттай. Харин BUG-02 (товчны өнгө буруу байгаа) болон BUG-01 (ямар ч мессежгүй хоосон мөр нэмэгдэх) зэрэг нь зөвхөн хүний нүдээр, визуалаар шалгах үед л илрэх боломжтой байсан.
