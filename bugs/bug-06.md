# BUG-06: API буруу JSON биетэй POST хүсэлтэд 400-ын оронд 200 OK буцаадаг

**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Нэг терминалд `node app.js` ажиллуул.
2. Нөгөө терминалд дараах командыг ажиллуул:
   ```
   curl -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" -d '{invalid json}'
   ```

**Хүлээгдэж байсан:** Спецификаци: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.»
**Бодит үр дүн:** `HTTP/1.1 200 OK` статус, `{"result":"OK"}` биеийг буцаав. Буруу оролтыг алдаагүй хүлээн авсан гэж мэдэгдэж байна.
**Ноцтой байдал:** Major. Клиент хүсэлт амжилттай боллоо гэж андуурч, буруу өгөгдөл сервер рүү орох эрсдэлтэй.
